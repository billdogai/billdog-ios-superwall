# BillDogSuperwallIntegration

Superwall presents the paywall, BillDog makes the purchase.
`SuperwallBillDogPurchaseController` is a SuperwallKit 4.x `PurchaseController`:
every purchase and restore from a Superwall paywall runs through
`BillDog.shared.purchase` / `restorePurchases()`, so receipt validation,
entitlements, analytics and webhooks stay on BillDog. The controller also keeps
`Superwall.shared.subscriptionStatus` in sync with BillDog's active entitlements.

Full guide: https://billdog.io/docs/superwall-integration

## Install

Available from BillDog 1.1.1-beta.5. Use the same version as the BillDog SDK
(`billdog-ios-spm` / the `BillDogFull` pod): this package depends on that exact
version, and on SuperwallKit 4.0.3 or later 4.x. With Xcode 26, use SuperwallKit
4.14.0 or later: older SuperwallKit releases don't compile with it.

### Swift Package Manager

```swift
.package(url: "https://github.com/billdogai/billdog-ios-superwall.git", exact: "1.1.1-beta.5"),

.target(name: "MyApp", dependencies: [
    .product(name: "BillDogSuperwallIntegration", package: "billdog-ios-superwall"),
])
```

In Xcode: File → Add Package Dependencies → `https://github.com/billdogai/billdog-ios-superwall.git`,
rule **Exact Version** `1.1.1-beta.5`, product `BillDogSuperwallIntegration`. It brings
`BillDogFull` (from `billdog-ios-spm`) and `SuperwallKit` with it.

### CocoaPods

```ruby
pod 'BillDogSuperwallIntegration', '1.1.1-beta.5'
```

It depends on `BillDogFull` at the same version and on `SuperwallKit` 4.x (4.0.3 or later).

## Use

```swift
import SuperwallKit
import BillDogFull
import BillDogSuperwallIntegration

BillDog.shared.configure(config: BillDogConfig(apiKey: "bd_public_live_xxxxxxxx"))

let purchaseController = SuperwallBillDogPurchaseController(entitlementMap: ["pro": "premium"])
Superwall.configure(apiKey: "pk_...", purchaseController: purchaseController)
purchaseController.startSyncingSubscriptionStatus()
```

## Why a separate package, and why source

The BillDog SDK does not depend on Superwall. SwiftPM fetches every dependency a
package declares, whichever products an app uses, so declaring SuperwallKit in
`billdog-ios-spm` would download SuperwallKit into every BillDog app. This package
holds only the Superwall glue (two Swift files) and is compiled with your app
against the SuperwallKit version you resolve; the BillDog SDK itself stays the
binary `BillDogFull`.

This repository is generated by the BillDog release
(`scripts/publish-ios-superwall-spm.sh` in the BillDog monorepo). Do not edit it by hand.
